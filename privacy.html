Kebijakan Privasi

Terakhir diperbarui: 30 September 2026

Selamat datang di Learn Earn. Kami berkomitmen melindungi privasi kamu. Kebijakan ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi data kamu.

1. Data yang Kami Kumpulkan

a. Data Akun

  • Nama tampilan (display name)
  • Alamat email (kalau login dengan Google)
  • ID pengguna unik
  • Avatar/profil

b. Data Aktivitas

  • Riwayat belajar (lesson yang diselesaikan)
  • Koin, XP, gems yang dikumpulkan
  • Riwayat top up dan withdraw
  • Referral (jika kamu mengajak teman)
  • Waktu login terakhir

c. Data Teknis

  • Jenis browser dan perangkat
  • Alamat IP
  • Informasi sistem operasi

2. Cara Kami Menggunakan Data

  • Menyediakan layanan (login, simpan progress belajar)
  • Memproses top up game/pulsa
  • Memproses withdraw ke DANA/OVO/GoPay
  • Menghitung reward/koin yang kamu dapat
  • Meningkatkan kualitas layanan
  • Mengirim notifikasi penting (misal: order sukses)

3. Keamanan Data

Kami menggunakan:

  • Enkripsi HTTPS untuk semua koneksi
  • Firebase Authentication untuk login aman
  • Firestore Security Rules untuk kontrol akses data
  • Server-side validation untuk transaksi

4. Berbagi Data dengan Pihak Ketiga

Kami TIDAK MENJUAL data kamu ke pihak lain. Kami hanya berbagi data dengan:

  • Firebase/Google — untuk layanan autentikasi & database
  • Cloudflare — untuk hosting & CDN
  • Penyedia layanan iklan — untuk menampilkan iklan (tidak personal)
  • Penyedia pembayaran (DANA/OVO/GoPay) — saat kamu withdraw

5. Cookie & Local Storage

Kami menggunakan cookie dan local storage untuk:

  • Menyimpan preferensi (dark mode, bahasa)
  • Cache agar website lebih cepat
  • Session login

6. Hak Kamu

Kamu berhak untuk:

  • Mengakses data kamu (lihat di halaman Profile)
  • Menghapus data kamu (hubungi support)
  • Memperbaiki data yang salah
  • Menarik diri dari layanan kapan saja

7. Data Anak-anak

Layanan kami tidak ditujukan untuk anak di bawah 13 tahun. Jika kamu tahu ada anak di bawah 13 tahun menggunakan layanan kami, hubungi kami untuk dihapus.

8. Perubahan Kebijakan

Kami dapat mengubah kebijakan ini kapan saja. Perubahan akan dipublikasikan di halaman ini dengan tanggal pembaruan.

9. Hubungi Kami

Pertanyaan tentang kebijakan privasi? Hubungi:

  • Email: support@duniamu.my.id
  • Website: duniamu.my.id
