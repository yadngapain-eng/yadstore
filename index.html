Cara belajar?

Pilih kategori → pilih lesson → jawab soal → dapat XP.

Cara top up?

Pilih game/pulsa → isi data → pilih nominal → bayar → upload bukti.

Metode bayar?

QRIS, DANA, GoPay, OVO, ShopeePay, BCA, BNI, BRI, Mandiri.

Bagaimana cara dapat koin?

Login harian, selesaikan lesson, nonton iklan, atau top up. Setiap aktivitas dapat koin!

Bagaimana cara withdraw?

Kumpulkan koin minimal Rp 10.000, lalu withdraw ke DANA/OVO/GoPay/ShopeePay/SEABANK.

Apakah website ini aman?

Ya. Kami pakai Firebase + server-side validation. Data kamu terenkripsi dan aman.
